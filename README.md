复扫雷 Complexweeper

扫雷，但雷是复数：四种雷分别是正实雷、负实雷、正虚雷、负虚雷；格子上的数字是它周围所有雷之和的模长平方。

翻开所有非雷格子就胜利。

原生 Windows 程序，Zig + Win32，没有第三方库和运行依赖。

介绍：
有四种雷：正实雷、负实雷、正虚雷和负虚雷，也就是+1、-1、+i和-i。
一个格子显示的数是周围所有雷之和的模长。
邻域最多 8 格，所以只可能出现 24 种数字：

0,1,2,3,4,5,6,7,8,√2,√5,√10,√13,√17,√26,√29,√34,√37,2√2,2√5,3√2,4√2,5√2;

正负雷数量相等时会互相抵消，这种1正1负的正负对我们称为“抵消对”
0和空白不是一回事。空白格子表示周围完全没有雷；0表示周围完全为抵消对。

规则：

当数字格子周围插上的旗帜数量等于真实雷数，且实虚比例符合真实比例或其倒数，则允许展开；可以利用这一点试探周围是否有抵消对。
谨记扫雷的胜利判定是翻开所有的格子，而不是插对全部的旗帜。
